# Git Learn Commands

A practical and easy-to-follow reference for learning and using **Git & GitHub**.

This repository brings together the most useful Git commands, from the basics of initializing a repository and managing branches to working with commits, remotes, and GitHub.

Each command is organized with simple explanations and practical examples, making this repository useful for both **learning Git step by step** and **quickly reviewing commands when you need them**.

Whether you're just getting started with Git or looking for a reliable reference to keep by your side, this repository is designed to help you **learn, practice, and use Git with confidence.**

---

## 🚀 What You'll Find Here

* Essential Git commands
* Branch and merge management
* Commit and commit message conventions
* Comparing changes with `git diff`
* Managing staged and unstaged changes
* Working with `git restore`, `git reset`, and `git revert`
* Using `.gitignore`
* Working with remote repositories
* GitHub workflows such as `push`, `pull`, `fetch`, and `clone`
* Useful Git shortcuts and VS Code integration

---

## 🎯 Goal

The goal of this repository is to build a **practical Git reference** that is easy to understand, easy to search, and useful in real-world projects.

> **Learn it. Practice it. Use it.**
